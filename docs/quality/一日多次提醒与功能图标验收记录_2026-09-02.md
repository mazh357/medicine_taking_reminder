# 一日多次提醒与功能图标验收记录

- 版本：`v0.3.0`
- Android `versionCode`：`3`
- 数据库 schema：`v6`
- 日期：`2026-09-02`
- 状态：`附条件通过｜仅限虚构数据内部测试`
- 数据门禁：`realPatientDataAllowed=false`

## 1. 本轮范围

本轮实现并验证以下变更：

- 同一药物可设置 1—8 个每日固定提醒时段，每个时段具有独立时间、计划数量和启停状态，共享药物库存；
- 时段支持新增、修改、暂停、恢复和退役，药物支持整体暂停与恢复；
- schema v5→v6 采用追加式迁移，保留既有药物、任务、历史、照片和库存流水；
- 每个启用时段生成独立任务、提醒意图、通知投影和幂等键；
- 库存预测合并全部启用且未退役时段的每日计划量；
- “今日、用药、事项、记录、设置”底部导航与五个主页面标题增加对应功能图标；
- App 版本升级为 `0.3.0`，Android `versionCode=3`。

本轮未增加联网、远程更新、医疗建议、视觉自动确认或真实患者数据能力。

已验证的关键领域规则包括：

- 同一药物最多 8 个时段，重复 `HH:mm`、非法时间和非正数量被拒绝；
- 一日三次计划生成三条相互独立、按时间排序的任务及提醒意图；
- 每个任务按人工确认的实际数量扣减共享库存；未服用不扣减，修订与撤销使用追加式反向流水；
- 药物整体恢复不会开启此前单独暂停的时段；如果当天已有启用时段经过，整体恢复从次日生效，避免补生成旧任务；
- 删除时段写入退役事实，不删除历史任务、照片或库存流水。
