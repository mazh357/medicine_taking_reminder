# ADR-012｜Android 系统备份边界

## 背景

Android Auto Backup 默认覆盖多数应用私有文件。SecureStore 密文恢复后可能因卸载时 Keystore 条目已删除而无法解密；照片、数据库和研究事件也不应未经用户主动授权离开设备。

## 决策

P0 同时为 Android 11 及以下提供 `fullBackupContent`，为 Android 12+ 提供 `dataExtractionRules`；排除数据库/WAL/SHM、媒体/缩略图、SecureStore、研究事件、导出暂存和诊断日志。P0 设置 `allowBackup=false` 作为防御性总开关，并通过最终 APK 验证 OEM 实际行为。未来 P1 备份只能使用应用主动生成的认证加密容器。

## 备选方案

- 依赖 SecureStore 默认排除：只覆盖 SecureStore，不覆盖其他健康数据。
- 允许设备到设备迁移：提高便利性，但当前缺少跨设备密钥/同意设计。
- 把数据放 cache/noBackup：媒体可避免备份，但 cache 可被系统清理，不能作为持久事实源。

## 代价

卸载、设备损坏或换机在 P1 前会丢数据；需要维护两套 Android 备份规则。

## 风险

只配置 Android 12+ 规则会遗漏旧系统；自定义规则可能覆盖 SecureStore 自动排除；某些 OEM 行为需实机验证。

## 验证

执行 [S07](../architecture/Phase0技术Spike方案_v0.1.md#s07auto-backup-排除零运行时联网与远程更新关闭)，静态检查与真机备份恢复都必须覆盖。
