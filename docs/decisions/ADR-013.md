# ADR-013｜研究数据流

## 背景

内部研究需要评估流程完成与模型回退，但原始照片、药名、疾病和自由文本不应被后台收集。当前无服务器，也不得用稳定设备标识追踪参与者。

## 决策

研究事件在加密数据库本机记录和聚合，仅含本次安装随机研究会话 ID、事件类型、粗粒度/相对时间、耗时区间、结果类别和模型版本。导出前展示字段预览并重新确认研究同意；用户主动调用系统分享面板后才可离开设备。默认排除照片、处方、药名、疾病、自由文本、广告 ID 和稳定硬件标识；导出动作写入本地审计。

## 备选方案

- 后台遥测：便于统计，但违反当前同意和离线边界。
- 导出完整数据库：最省开发，但严重过度收集且难以去标识。
- 完全不记录指标：无法回答研究问题。

## 代价

研究人员不能实时监控；参与者可能不导出或导出不完整；需单独维护字段白名单和版本。

## 风险

事件组合仍可能重识别；系统分享目的地不由 App 控制；“撤回”不能删除已经交付给研究方的副本，必须在同意书和研究 SOP 说明。

## 验证

执行 S07 的零后台联网和 S08 的主动导出演练；隐私负责人逐字段签署白名单，并对小样本组合进行重识别攻击测试。

## 依据（访问日期：2026-08-23）

- 本 ADR 依据离线 MVP 的研究同意与数据最小化要求；适用地区未冻结，因此不宣称满足特定地区法律。
