# ADR-015｜公开测试前的应用级备份

## 背景

P0 禁止系统自动备份，因此卸载、换机或设备损坏会丢数据。面向公开测试前必须提供用户可控且能检测篡改的离线备份和原子恢复，但不能扩大本轮 Spike 为正式备份开发。

## 决策

P1 必须设计版本化、认证加密的应用级容器，包含 schema/媒体/模型与内容版本清单、完整性校验和恢复前预检。备份由用户主动生成并设置独立凭据；恢复先写隔离区，完成认证、版本和引用完整性验证后原子替换。忘记密码平台不可找回。跨版本、篡改、中断和旧模型场景通过演练前，不允许公开测试。

## 备选方案

- Android Auto Backup：密钥和同意边界不可控，已由 ADR-012 排除。
- 明文 ZIP/JSON：易泄露且不能认证篡改。
- 账号云同步：属于未来联网产品，范围和合规成本不同。

## 代价

用户需管理备份密码和文件；版本兼容、媒体体积、恢复空间与中断处理复杂。

## 风险

弱密码、密码丢失、恶意超大容器、路径穿越、降级攻击、恢复中断和旧版本错误解释均需单独威胁建模。

## 验证

P0 仅在 S07 证明系统备份被排除。公开测试 Gate D 前另建备份格式 ADR/规范，完成正确密码、错误密码、篡改、截断、空间不足、跨版本和原子回滚演练；不得由本 ADR 的纸面接受替代。
