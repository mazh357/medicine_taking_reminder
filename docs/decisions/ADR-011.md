# ADR-011｜离线代码、内容与诊断

## 背景

P0 不包含服务器或账号，真实患者研究也要求数据仅在主动导出时离开设备。远程更新、配置、崩溃和分析 SDK 会形成未声明的数据流或改变已审核文案/模型。

## 决策

发布配置显式设置 `updates.enabled=false`；代码、模型、阈值、迁移和安全文案只随签名安装包升级。不集成远程配置、分析、广告、归因或崩溃上报 SDK。诊断使用脱敏、限额、可清除的本地环形日志。release-like 包的核心流程不得发起网络请求。

## 备选方案

- EAS Update：修复快，但运行时内容可能绕过已签署安装包。
- 自托管热更新：仍是远程动态代码，且增加服务端边界。
- 远程崩溃上报：排错方便，但违反当前数据最小化和零后台传输。

## 代价

修复必须重新构建和分发；现场故障排查依赖主动诊断包和真机复现。

## 风险

Expo 更新默认开启，漏配会产生外联；间接依赖可能包含遥测或端点。

## 验证
