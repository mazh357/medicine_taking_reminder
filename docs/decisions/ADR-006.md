# ADR-006｜拍摄方式

## 背景

拍照的目标是留下视觉记忆凭证，而不是证明吞服。首版需降低每日操作负担，同时保留多药逐项确认。

## 决策

使用 `expo-camera` 手动快门。方案默认整组一张，照片可关联多个任务药项；用户可预先选择逐药模式。拍摄质量提示不阻止快门；相机权限或加密失败可记录原因后走无照片人工确认。不得用整组照片一次性覆盖逐药确认。

## 备选方案

- 自动快门：减少一次点击，但需要稳定的画面门控且超出 MVP。
- 逐药强制拍摄：关联清晰但增加长期负担。
- 不拍照只打卡：失去本产品核心记忆凭证假设。

## 代价

整组照片的视觉分析只能可靠给出总数/整组异常，不能强行定位药项；逐药模式步骤更多。

## 风险

用户可能在拍照后未服用；相机缓存明文需由 ADR-005 处理；快速连点可能产生重复照片。

## 验证

执行 [S03](../architecture/Phase0技术Spike方案_v0.1.md#s03camera--aes-gcm-加密媒体流水线)，并由交互/数据契约测试证明照片关联与逐药事实正交。
