# ADR-007｜本地提醒可靠性

## 背景

Android 通知权限、精确闹钟特殊访问、Doze、强制停止和 OEM 省电均可能影响本地通知。系统调度记录不能成为服药或计划事实源。

## 决策

SQLite 保存 `ReminderIntent`；`expo-notifications` 系统计划是可丢弃投影。只调度有限滚动窗口的一次性本地通知，payload 仅含 opaque ID。应用前台、方案变化、重启和时区变化时 reconciliation。Android 原生能力端口查询 `canScheduleExactAlarms()` 并打开系统设置；能力不可用时改用近似提醒、显示持续健康告警和测试提醒，不承诺绝对准时。

## 备选方案

- 远程推送：违反离线 P0，且仍不能保证送达。
- 常驻后台定时器：受系统限制并增加电量消耗。
- 一次调度无限未来重复通知：难以正确处理处方版本、时区和撤销。

## 代价

需原生能力检测、投影表和周期重建；近似提醒可能显著延迟。

## 风险

`SCHEDULE_EXACT_ALARM` 可被拒绝/撤销，强制停止会取消行为预期；`USE_EXACT_ALARM` 使用范围受平台/商店政策限制，不作为默认选择。
