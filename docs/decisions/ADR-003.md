# ADR-003｜本机事实源

## 背景

处方、逐药确认、库存和撤销必须在进程强杀、重启和页面切换后保持一致。React 状态和轻量 store 不提供事务或持久化事实审计。

## 决策

SQLCipher SQLite 是健康数据唯一事实源；repository 是唯一写入口。Zustand 只保存相机 UI、筛选和未提交导航草稿，任何需恢复的健康事实提交后必须从数据库重新读取。多表写使用 `withExclusiveTransactionAsync` 或等价的独占事务，避免异步查询误入事务。

## 备选方案

- Zustand/AsyncStorage 持久化：简单但无关系约束和事务边界。
- Redux + 持久化：可追踪 UI 动作，但不能替代数据库事务。
- 云数据库：违反离线 P0。

## 代价

需要手写 repository、迁移和 view model；UI 必须处理数据库异步加载。

## 风险

缓存与事实源短暂不一致；误用普通异步事务可能把作用域外查询纳入事务。
