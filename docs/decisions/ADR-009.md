# ADR-009｜视觉输出边界

## 背景

药片外观受光线、相机、批次、遮挡和相似药物影响。首版没有足够证据做开放式识药、剂量判断或安全判断。

## 决策

视觉只执行画质门控、药片样物体总数和个人单一当前基准内的异常分数。用户可见仅 `suspected_change` 和 `unable`；`no_anomaly_signal` 只作为内部诊断值，不展示“通过/正确/安全”。半片、破损、透明胶囊、遮挡重叠、同一种药的新旧外观并用、无基准和模型异常强制 `unable`；合法整组多药同框不因此回退。首版不输出尺寸变化原因。结果不得修改服药状态或库存。

## 备选方案

- 开放式药名识别：风险和数据需求远超 MVP。
- 二分类“正确/错误”：会制造错误安全感。
- 完全不做视觉：可作为模型未达门槛时的正式降级。

## 代价

模型价值更保守，人工核对仍是必需步骤；`no_anomaly_signal` 无正向用户反馈。

## 风险

疑似变化仍会误报/漏报；内部状态可能被后续 UI 误用成绿色通过。
