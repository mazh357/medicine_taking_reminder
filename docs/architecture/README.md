## 当前个人测试版实现索引

- 数据库：schema v4，由 v3 原地迁移并保留既有数据。
- 库存预测：只读库存流水和当前每日固定计划；关闭补药提醒仍保留预测。
- 事项：复诊、取药和检查事项只追加审计，不提供单项物理删除。
- 通知：数据库保存意图，系统通知 ID 属于可重建投影；取消失败保留旧 ID 和 `cancel_pending`。
- 全部清除：物理删除数据库主文件、WAL、SHM 和密钥后，才允许按空库路径重建。
