# 长期用药助手

把提醒、照片和记录放在一起，少一点“刚才记过了吗？”的疑惑。

这是一个 Android 用药管理 Demo，可以体验定时提醒、拍照留存、逐药记录、库存预测，以及复诊、检查和取药事项管理。**安装后无需注册账号，核心功能可离线使用，也不需要连接电脑。**

> [!NOTE]
> 当前版本为实验性 Demo，仅用于虚构数据体验，不用于管理真实用药或保存真实健康信息。无需实际服药即可完成下面的体验流程。它不是医疗建议工具，也不能作为唯一的用药提醒来源。

## 下载安装

**发布状态：安装包尚未上传到 GitHub。** 当前正在本地准备首个版本；以下步骤供本仓库发布安装包后使用。如果 Releases 中没有 APK，请等待发布，不要下载源码压缩包尝试安装。

### 1. 用手机下载 APK

发布后，在手机浏览器打开本仓库：

1. 找到 **Releases（发行版）**，进入提供手机安装包的版本；手机页面可能需要向下滚动。
2. 展开 **Assets（资源）**，下载文件名带有 **`arm64-v8a`**、以 **`.apk`** 结尾的文件。
3. 当前准备发布的手机包名称为：

   `long-term-medication-assistant-v0.3.0-arm64-v8a-internal.apk`

   文件大小约 **68.6 MiB**，SHA-256 为 `D7D6E288D02ADFBE23A03F4E3CCDE01C9F03182FC64D8811B28329E821139C4F`。还需为安装和后续照片留出空间。

**不要下载 `x86_64` 包**，它用于电脑上的 Android 模拟器；**`Source code (zip)` 和 `Code → Download ZIP` 是源码，不是手机安装包**。找不到发行版入口时，可参考 [GitHub 的 Releases 查看说明](https://docs.github.com/en/repositories/releasing-projects-on-github/viewing-your-repositorys-releases-and-tags)。

### 2. 安装到手机

1. 下载完成后，点击浏览器下载列表中的 APK，或在手机“文件管理 → 下载”中打开它。
2. 如果系统提示“允许来自此来源的应用”，确认文件来自本仓库后，仅为本次使用的浏览器或文件管理器允许安装。
3. 按系统提示完成安装，打开 **长期用药助手**。
4. 安装后可关闭刚才开启的来源安装权限。

通常不需要电脑、USB 调试、Expo Go 或任何编程工具。不同手机的安装入口和限制可能不同；若系统明确拦截、显示来源异常或设备不兼容，请停止安装并反馈，**不要为安装 Demo 关闭系统安全防护**。来源安装风险见 [Android 官方说明](https://support.google.com/android/answer/9457058?hl=zh-Hans)。

### 哪些手机可以尝试？

- 当前手机包面向 **Android 7.0 及以上、64 位 ARM 系统（arm64-v8a）**；这是安装包声明的最低要求，不代表所有机型都已验证。
- 暂不提供 iPhone 版、32 位 Android 版，或不能安装 Android APK 的系统版本。
- 当前 ARM64 包已生成，但**真实手机运行仍待验证**，采用测试签名，尚非正式发布版本。请以对应 Release 的兼容性说明为准。

## 第一次使用

建议先用下面的一组虚构数据，走完一次“提醒 → 拍照 → 确认 → 查看库存”的流程。

### 1. 新增一项测试计划

打开底部 **用药 → 新增药物**，填写：

| 内容 | 体验用示例 |
| --- | --- |
| 药物名称 | 测试药物 A |
| 当前库存 | 20 |
| 提醒时段 1 | 当前时间之后 2 分钟，计划数量 1 |
| 提醒时段 2（可选） | 与第一个时段不同的时间，计划数量 0.5 |

每个提醒时段都可独立设置时间和计划数量；时间通过小时、分钟两列选择，采用 24 小时制。同一药物最多设置 8 个每日时段，且不能出现重复时间。点击 **保存**，再回到 **今日**，每个时段会显示为一条独立任务，并共享同一库存。

### 2. 检查提醒

在系统询问时允许通知权限。也可以进入 **设置 → 设备与提醒 → 1 分钟后测试提醒**，检查本机是否能收到通知。

提醒可能受通知权限、省电模式、勿扰设置和系统后台限制影响。若没有收到，先在设置页检查状态；不要把 Demo 当作可靠的唯一提醒来源。

### 3. 拍照并完成一次模拟记录

1. 在 **今日** 点击测试任务卡片；尚未到时间时，确认是否现在开始记录。
2. 允许相机权限。用不含个人信息的测试物品拍摄，例如放在纯色纸面上的纽扣；保持光线充足、物品分开。
3. 点击 **手动拍照并保存**。
4. 在“照片辅助信息”页面查看结果，点击 **继续逐药确认**。
5. 选择 **按计划量服用**，点击 **确认此药**，完成这次虚构记录。

这里只是在测试记录功能，**不需要也不应为了体验而实际服药**。如果无法拍照，可点击 **这次无法拍照**，选择原因后继续人工记录。

照片保存后任务还没有完成：必须逐项确认，才会记录实际数量并更新库存。当前计数功能只尝试数出画面中的物体，不识别药名、不核对剂量，也不证明已服药；显示“无法判断”时仍可继续人工记录。

### 4. 看看记录和库存

- 到 **记录** 打开刚才的记录，查看照片和已填写的数量。
- 回到 **用药**，测试药物 A 的库存应由 **20 变为 19**。
- 如果选择“未服用”，实际数量为 0，库存不会扣减；选择“与计划量不同”时，按填写的实际数量计算。

至此，已完成一次体验。

## 日常操作入口

| 页面 | 可以做什么 |
| --- | --- |
| **今日** | 查看任务、当前库存和最近一条待处理事项倒计时；点击未完成任务继续记录，点击已完成任务查看详情。 |
| **用药** | 新增或修改每日计划，暂停、恢复计划，查看库存预测并校正库存。 |
| **事项** | 添加、编辑、完成或取消复诊、检查、取药安排。 |
| **记录** | 查看历史、筛选结果、修改记录、重新拍照和管理照片。 |
| **设置** | 检查权限与提醒，切换主题和文字大小，管理或清除本机数据；进入独立的照片比较实验。 |

底部的“今日、用药、事项、记录、设置”均配有对应图标；当前页面使用主色图标，文字标签始终保留，便于识别和读屏。

### 如何给同一药物设置一天多次提醒？

新增药物时，先填写第一个时段，再点击 **添加服用时段** 增加第二个或更多时段。每个时段可以使用不同的计划数量，例如 `08:00 / 1`、`14:00 / 0.5`、`20:00 / 1`。

保存后，可在 **用药 → 对应药物** 中单独修改、暂停、恢复或删除某个时段，也可以暂停整个药物计划。单独暂停的时段不会因为恢复整个药物而自动开启；删除时段不会删除已有历史记录。一天内的多个时段共用该药物的库存，库存预测会合并计算所有已启用时段。

### 记录错了怎么办？

在 **记录 → 对应记录 → 修改记录** 中修改结果或实际数量，并填写修订原因。旧记录会保留，库存会随修订重新计算。

点击 **重新拍照** 可追加照片，不会替换旧照片，也不会再次扣减库存。若只想删除一张照片，进入 **查看与管理照片**，再选择 **永久删除照片**；这不会删除服用记录。

当天超过提醒时间的未完成任务，仍可从 **今日** 点击进入补记录；原来的晚服或漏服历史会保留。**补记录不是补服建议。**

### 如何设置复诊、检查和取药提醒？

打开 **事项 → 新增事项**：

1. 选择“复诊”“检查”或“取药”；
2. 填写标题、日期和时间；日期按 `YYYY-MM-DD` 填写，时间使用时分选择器；
3. 按需关联一项药物，选择提前提醒时间并保存。

最近一条未完成事项会出现在 **今日** 的“下一个事项”卡片中。完成后，在 **事项** 页点击 **标记完成**。

### 如何使用库存预测？

在 **用药** 页面查看当前库存和预计用尽日期；通过 **修改计划与库存** 设置补药提醒或校正库存，校正时需填写原因。

预测依据已录入的计划、库存和确认记录推算，不会自动知道你新拿了多少药，也不能替代实际清点。没有记录的消耗或库存变化会使预测不准确。

### 照片比较实验怎么用？

当前版本提供 **设置 → 照片比较实验**。它与日常拍照打卡分开，不读取或修改用药计划、服用记录或库存。

1. 用“样本 A”这样的匿名标签新建样本，不填写真实药名。
2. 在哑光纯色背景上放一个测试物品，分别拍正面、背面；每面各一张。
3. 两张照片均通过清晰度和单对象检查后，点击 **激活此基线**。未通过时可以重拍，旧照片仍保留。
4. 选择 **拍照并分析此样本**，拍摄同一样本的 1—8 个分离对象。
5. 查看计数，手工标记整体或各个对象的外观，或标记无法判断。可以预览、重试分析或删除照片。

**当前只开放受控背景计数和人工标注，尚未开放自动外观比较。** 安装包内已放入通用图像模型，但药片评测数据与阈值尚未验证，不能将它当作识药工具。半片、破损、透明胶囊、混批、遮挡或反光时，请选择不支持情况，仅保存照片。不会上传照片，也不会调用云端模型。

换批次请 **建立新批次基线**，不要覆盖旧版本。删除活动基线的一面会停用该基线；删除实验照片不会删除用药记录。

## 常见问题

**需要一直联网吗？**

不需要。下载安装包需要网络，安装后的核心功能离线运行；无需账号，也没有云端同步。

**为什么拍完照片还要确认？**

拍照和记录服用是两件事。只有点击“确认此药”才会保存该药项的实际数量并扣减库存，自动计数不会替你确认。

**拍照失败或计数不准怎么办？**

先检查相机权限、剩余空间和光线，按页面提示重新拍摄。也可选择“这次无法拍照”并人工记录；计数无法判断不影响继续确认。

**为什么锁屏提醒没有药名？**

当前锁屏通知使用中性文案，避免旁人从通知看到药名或事项内容。打开应用后可以查看具体任务。

**如何展开历史筛选？**

点击 **记录** 页面右上角的漏斗图标，选择日期、药物或结果；再次点击可收起。收起筛选区不会清空已选条件。

**照片在哪里？换手机后还在吗？**

照片和记录保存在本机应用内，采用本地加密存储，不会自动进入系统相册。当前没有可用的跨设备同步或完整备份恢复功能；卸载、清除数据或换手机可能导致记录无法找回。

**更新版本需要先卸载吗？**

通常先尝试安装同来源的新 APK，并以 Release 的升级说明为准。不要为了处理安装失败而直接卸载或清除数据，这会丢失本机记录；出现签名冲突、版本不兼容等提示时，请先反馈。

**提示“应用未安装”或“解析包失败”怎么办？**

确认下载的是文件名包含 `arm64-v8a` 的 `.apk`，文件已完整下载，系统支持安装 Android APK，且存储空间充足。仍然失败时，记录完整提示、手机型号和 Android 版本后反馈；不要反复关闭系统防护尝试安装。

**怎样清空体验数据？**

进入 **设置 → 照片与数据 → 清除全部本机数据** 并确认。此操作会清除照片、记录、计划、库存和提醒，无法恢复。
